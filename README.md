# NightDrive

A personal SwiftUI map for iOS 26 and later, with a dark navy map, cyan streets and red 3D buildings. Built with MapLibre Native and OpenFreeMap / OpenMapTiles / OpenStreetMap data.

## Milestones

1. Repository and development setup.
2. Native map, original map style, foreground GPS and adaptive camera controls.
3. Xcode build, regular iPhone and iPhone Duo simulator validation.
4. Later: routing, then CarPlay (separate approval and implementation).

Signing is intentionally unconfigured until the Apple Developer team is confirmed. No CarPlay entitlement, TestFlight upload, App Store submission or Apple approval request is part of this setup.

This is an independent personal project, not affiliated with CD Projekt Red. No game assets or third-party app code are included.
